# WearCast — Weather & Outfit Advisor

WearCast — мобильное приложение на Flutter, которое показывает актуальную погоду, прогноз на 7 дней и помогает подобрать одежду по погоде.

## Основные функции

- Главная страница с текущей погодой
- Прогноз погоды на 7 дней
- Гардероб с категориями одежды
- Экран с деталями образа
- Профиль пользователя
- Светлая и тёмная темы
- Навигация между экранами
- Получение данных из Open-Meteo API
- Кеширование погоды для офлайн-доступа
- Обработка загрузки и ошибок

## Использованные технологии

- Flutter и Dart
- Provider — управление состоянием
- GoRouter — навигация
- HTTP — запросы к API
- Open-Meteo API — данные о погоде
- Hive — локальное кеширование
- SharedPreferences — сохранение настроек

## Архитектура проекта

Проект разделён на слои:

- `core` — темы приложения и маршрутизация
- `data` — API, сервисы, кеш и реализация репозитория
- `domain` — сущности и интерфейсы репозиториев
- `presentation` — экраны, виджеты и Provider

Используется Dependency Injection через Provider.

## Экраны приложения

1. Home — текущая погода и рекомендации
2. Forecast — прогноз погоды
3. Wardrobe — гардероб
4. Profile — профиль и настройки
5. Outfit Details — подробная информация об образе

## Запуск проекта

1. Установить Flutter SDK.
2. Открыть проект в VS Code.
3. Выполнить команды:

```bash
flutter pub get
flutter run -d chrome
```

## Проверка проекта

Статический анализ:

```bash
flutter analyze
```

Запуск тестов:

```bash
flutter test
```
